# Scooter Health Intelligence System

Predictive maintenance platform for two-wheelers using Spring Boot, FastAPI ML, React, and Agentic GenAI alerts.

**Author:** Gaurav Gadekar
**Institution:** MIT ADT University, Pune — B.Tech CSE (AI & Edge Computing), Batch 2026
**Contact:** gauravgadekar2201@gmail.com

## Tech Stack
- Frontend: React 18 + Vite + TailwindCSS + Recharts
- Backend: Java 21 + Spring Boot 3.3.5 + Spring Security + JWT
- Database: PostgreSQL (Supabase)
- ML Service: Python 3.12 + FastAPI + scikit-learn
- GenAI: Google Gemini (via Spring WebClient)
- Deployment: Render + Vercel + Supabase
